## 二、系统性设计方案

### 2.1 架构原则

1. **单一职责**: 每个模块只做一件事
2. **统一入口**: 所有飞书事件通过统一网关处理
3. **卡片即服务**: 卡片定义与业务逻辑分离
4. **双向同步**: 飞书操作 ↔ 系统数据实时同步

### 7.1 统一网关 (feishu/gateway.py)

```python
from fastapi import APIRouter, Request
from .handlers import task_handler, approval_handler, chat_handler, menu_handler

router = APIRouter(prefix="/api/feishu", tags=["Feishu"])

# 事件处理器注册表
EVENT_HANDLERS = {
    # 卡片回调
    "task_accept": task_handler.handle_accept,
    "task_reject": task_handler.handle_reject,
    "task_progress": task_handler.handle_progress,
    "approval_approve": approval_handler.handle_approve,
    "approval_reject": approval_handler.handle_reject,
    # 菜单事件
    "my_tasks": menu_handler.show_my_tasks,
    "update_status": menu_handler.show_update_form,
    "start_approval": menu_handler.show_approval_form,
}

@router.post("/webhook")
async def feishu_webhook(request: Request):
    """统一飞书事件入口"""
    body = await request.json()

    # 1. URL 验证
    if "challenge" in body:
        return {"challenge": body["challenge"]}

    # 2. 解析事件类型
    event_type = parse_event_type(body)
    action_type = parse_action_type(body)

    # 3. 路由到对应处理器
    handler_key = action_type or event_type
    handler = EVENT_HANDLERS.get(handler_key)

    if handler:
        return await handler(body)

    return {"code": 0}
```

### 7.2 统一卡片基类 (feishu/cards/base.py)

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, List

class BaseCard(ABC):
    """飞书卡片基类"""

    def __init__(self, title: str, color: str = "blue"):
        self.title = title
        self.color = color

    @abstractmethod
    def build_content(self) -> List[Dict]:
        """构建卡片内容区域"""
        pass

    @abstractmethod
    def build_actions(self) -> List[Dict]:
        """构建操作按钮"""
        pass

    def build(self) -> Dict[str, Any]:
        """构建完整卡片"""
        return {
            "config": {"wide_screen_mode": True},
            "header": {
                "title": {"tag": "plain_text", "content": self.title},
                "template": self.color,
            },
            "elements": [
                *self.build_content(),
                {"tag": "hr"},
                {"tag": "action", "actions": self.build_actions()},
            ],
        }
```

                    ),
                },
            },
        ]

    def build_actions(self):

        return [

        ]

## 九、总结

### 当前问题
1. 代码分散，维护困难
2. 没有统一的设计规范
3. 每次加功能都是临时修补

### 解决方案
1. **模块化**: 创建 feishu/ 独立模块
2. **分层**: 网关 → 处理器 → 服务 → 卡片
3. **统一**: 事件路由、卡片模板、SDK 封装
4. **可扩展**: 新功能只需添加处理器和卡片

### 预期收益
- 开发效率提升 50%
- 代码可维护性大幅提升
- 新功能接入标准化
- 飞书与系统数据实时同步
