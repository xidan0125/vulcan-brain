# Tech Researcher - 技术调研专家

联网搜索 + 技术分析，快速获取最新技术情报。

## 快速使用

```bash
# 技术选型
python3 run_skill.py research "KùzuDB 和 Neo4j 哪个更适合单机离线场景?"

# 论文解读
python3 run_skill.py research "解读 GraphRAG 论文的核心思想"

# 竞品调研
python3 run_skill.py research "2025年主流的开源 RAG 框架有哪些?"

# 最佳实践
python3 run_skill.py research "vLLM 生产环境部署最佳实践"
```

## 适用场景

- 新技术评估和选型决策
- 论文/技术文档快速理解
- 开源项目功能对比
- 问题解决方案搜索
- 行业趋势分析

## 输出特点

- 结构化对比表格
- 明确的推荐结论
- 附带参考来源链接
- 标注信息时效性
