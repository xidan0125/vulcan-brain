# Enterprise Integrator - 企业集成专家

飞书、MS365 等企业 SaaS API 对接专家。

## 快速使用

```bash
# 飞书 API
python3 run_skill.py ops "如何用飞书 API 发送交互式卡片消息?"

# MS365 邮件
python3 run_skill.py ops "MS Graph API 如何实现邮件增量同步?"

# 审批流程
python3 run_skill.py ops "飞书审批流程 API 怎么用?"

# Webhook
python3 run_skill.py ops "飞书事件订阅的签名验证怎么实现?"
```

## 覆盖范围

### 飞书开放平台
- 消息 (文本/富文本/卡片)
- 审批流程
- 多维表格 (Bitable)
- 通讯录
- 任务管理

### Microsoft 365
- 邮件 (Graph API)
- 日历/会议
- OneDrive 文件
- Teams

### 通用模式
- OAuth 2.0 认证
- Webhook 处理
- Rate Limiting

## 别名

- `ops` (推荐)
